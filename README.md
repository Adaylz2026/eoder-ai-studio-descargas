# Eoder AI Studio · Descargas

Aquí se publican los instaladores de **Eoder AI Studio** para Windows (Eoder Studios).

- Descarga la última versión en **[Releases](https://github.com/Adaylz2026/eoder-ai-studio-descargas/releases/latest)**: el archivo `Eoder-AI-Studio-Instalador-X.Y.Z.exe`.
- Una vez instalado, el programa se actualiza solo desde este repositorio.

El código del programa no está aquí: este repositorio solo contiene las versiones publicadas.
